# Davídkova dráha

Stavebnice dřevěné vláčkodráhy pro iPad pro malé strojvůdce. Stavíš koleje, výhybky, mosty, tunely, točnu, přejezd, semafor, nádraží a myčku a pak po nich pouštíš vláčky.

Otevřete v Safari a zvolte Sdílet → Přidat na plochu. Hra pak funguje i bez internetu.

Ovládání: díl přetáhni z lišty dole (nebo ho vyber a ťukej na trávu), ťuknutím díl otočíš, tažením přesuneš, tažením zpět do lišty smažeš. Žlutá páčka přepíná výhybku, ťuknutí na semafor nebo točnu je přepne.
